# C언어 기반 콘솔 요트다이스 게임 (Yacht Dice)

C언어의 배열, 조건문, 반복문, 함수 분리 구조를 활용해 구현한 텍스트 기반 콘솔 요트다이스 게임 프로젝트입니다.  
2024년 2학년 1학기 `프로그래밍 설계` 강의 팀 프로젝트로 진행했으며, 턴제 게임 로직, 점수 계산, 콘솔 UI, 기능별 모듈 분리를 함께 다뤘습니다.

> 이 저장소는 2024년 2학년 1학기 과제물을 바탕으로,  
> 당시 로컬 환경에 보관하던 소스코드를 **포트폴리오 및 코드 아카이브 목적**으로  
> 개인 GitHub 저장소에 옮겨 정리한 버전입니다.  
> 원 프로젝트는 Git 기반 협업으로 진행되지 않았으며, 팀원별로 각자 작업한 뒤 최종 통합하는 방식으로 마무리했습니다.

## 3. 실행 방법

### 1) 실행 전 준비

- 본 프로젝트는 `windows.h`를 사용하므로 Windows 환경이 필요합니다.
- Visual Studio 2022 이상에서 실행하는 것을 권장합니다.

### 2) 실행 방법

1. 저장소를 다운로드하거나 Clone 합니다.
2. `yacht.sln` 파일을 열어 Visual Studio에서 프로젝트를 불러옵니다.
3. 빌드 후 실행하거나 `Ctrl + F5`로 콘솔 프로그램을 실행합니다.
4. 콘솔 안내에 따라 인원 수, 닉네임, 게임 진행 순서를 입력합니다.

### 3) 주요 사용 흐름

- **게임 시작 설정**: 플레이 인원 수 및 닉네임 입력
- **주사위 굴리기**: 난수 기반 주사위 생성 및 리롤 수행
- **점수 선택**: 족보에 맞는 점수 확인 후 카테고리 선택
- **승패 판정**: 모든 턴 종료 후 최종 점수 비교

### 핵심 포인트

- **기능별 모듈 분리**
  - 게임 시작, 주사위 굴리기, 점수 계산, 점수판 출력 기능을 파일별로 분리
  - 단일 파일에 모든 로직을 몰아넣지 않고 역할별 구조를 나누어 구현

- **턴제 게임 흐름 제어**
  - 플레이어 순서에 따라 주사위 굴리기와 점수 선택이 반복되는 구조
  - 여러 플레이어가 콘솔 환경에서 순차적으로 플레이할 수 있도록 구성

- **점수 계산 및 추천 로직**
  - 족보별 점수를 계산하고 선택 가능한 항목을 구분
  - 플레이어가 현재 턴에서 어떤 점수를 선택할 수 있는지 확인 가능하도록 구현

- **콘솔 UI 구성**
  - `windows.h` 기반 좌표 출력 방식으로 점수판과 게임 화면을 정리
  - 단순 출력이 아니라 상태를 구분해서 볼 수 있는 콘솔 인터페이스를 구성

### 주요 파일

- `main.c`
  - 전체 게임 루프 제어
  - 플레이어 턴 전환 및 진행 흐름 담당

- `start.c`
  - 게임 시작 전 설정
  - 인원 수 입력, 닉네임 검증, 규칙 출력 담당

- `rolldice.c`
  - 주사위 생성 및 리롤 기능 담당
  - 난수 기반 주사위 값 처리

- `score.c`
  - 족보별 점수 계산
  - 점수 선택 및 계산 로직 담당

- `scoreboard.c`
  - 콘솔 점수판 출력
  - 게임 상태 시각화 담당

## 7. 트러블 슈팅

### 1) 입력 버퍼 처리 문제
잘못된 문자나 숫자를 입력했을 때 입력 버퍼가 남아 무한 반복이나 오작동이 발생하는 문제가 있었습니다.  
입력 실패 이후 버퍼를 비우는 처리를 추가해 다음 입력이 정상적으로 진행되도록 수정했습니다.

### 2) 모듈 통합 시 변수 충돌
팀원별로 따로 작성한 코드를 합치는 과정에서 동일한 변수명 중복과 선언 충돌이 발생했습니다.  
공통 변수는 한 곳에서만 정의하고, 다른 파일에서는 참조하도록 정리해 충돌을 줄였습니다.

### 3) 예외 입력에 대한 처리 한계
플레이어 이름 길이 초과, 비정상적으로 큰 숫자 입력 등 경계값 처리에서 프로그램이 불안정해지는 문제가 있었습니다.  
당시에는 정상적인 게임 흐름 구현을 우선했기 때문에 일부 예외 상황은 충분히 보완하지 못했고, 이후 입력 검증의 중요성을 크게 느꼈습니다.
